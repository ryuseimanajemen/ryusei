// 01 — Fitur Utama

Apa yang Bisa Dilakukan Ryusei?

Semua fitur dirancang khusus untuk event virtual live streaming agar pengalaman peserta, juri, dan panitia menjadi lebih terstruktur dan menyenangkan.

⚡
Skor Real-Time

Skor dari semua juri langsung terupdate secara bersamaan tanpa perlu memuat ulang halaman. Semua peserta bisa melihat perubahan skor secara langsung berkat Firebase RTDB.

👨‍⚖️
Multi-Juri

Dukung banyak juri sekaligus. Setiap juri memiliki panel akses tersendiri dan memberikan nilai secara terstruktur untuk setiap kriteria penilaian.

🏆
Leaderboard Otomatis

Ranking peserta diperbarui otomatis berdasarkan total nilai. Top 3 mendapatkan tampilan medali emas, perak, dan perunggu beserta rincian skor per kriteria.

✅
Sistem Persetujuan Peserta

Admin bisa menyetujui atau menolak pendaftaran peserta sebelum event dimulai. Peserta yang ditolak tidak akan masuk ke daftar peserta aktif event.

🔑
Kode Unik Peserta

Setiap peserta yang mendaftar mendapatkan kode unik. Kode ini digunakan untuk mengecek status pendaftaran tanpa perlu login atau membuat akun.

📱
Mobile Friendly

Tampilan dioptimalkan untuk semua ukuran layar. Peserta, juri, dan admin bisa mengakses platform dari smartphone dengan nyaman.

🎭
Manajemen Banyak Event

Buat dan kelola banyak event sekaligus dari satu dashboard. Setiap event memiliki peserta, juri, dan leaderboard tersendiri yang terpisah satu sama lain.

🖼️
CMS Landing Page

Admin dapat mengubah tampilan halaman utama (landing page) langsung dari dashboard tanpa perlu mengedit kode — mulai dari teks, gambar, hingga informasi kontak.

// 02 — Alur Kerja

Bagaimana Event Berjalan?

Dari persiapan hingga pengumuman pemenang — semua dilakukan di satu platform.

2

Buat Event Baru

Admin membuat event baru dari dashboard. Setiap event bisa dikonfigurasi dengan nama, deskripsi, jadwal, dan informasi event lainnya. Event yang sudah dibuat langsung muncul di halaman publik.

Dashboard Admin Manajemen Event
3

Peserta Mendaftar

Peserta mengisi form pendaftaran di halaman publik: memilih event, memasukkan username, link profil/aplikasi, dan jam tampil. Setelah mendaftar, peserta mendapatkan kode unik untuk memantau status.

Form Publik Kode Unik
4

Admin Menyetujui Pendaftaran

Admin meninjau daftar peserta yang masuk dan memutuskan untuk menyetujui atau menolak. Hanya peserta yang disetujui yang akan tampil dalam sistem penilaian dan leaderboard.

Approval System Manajemen Peserta
5

Juri Masuk & Memberi Nilai

Juri login ke panel khusus juri menggunakan akun yang disiapkan admin. Setiap juri memberikan nilai pada 5 kriteria untuk masing-masing peserta. Nilai langsung tersimpan dan tersinkronisasi ke semua perangkat.

Panel Juri 5 Kriteria Real-time Sync
6

Leaderboard Diperbarui Otomatis

Setiap nilai yang diinput langsung mengubah posisi di leaderboard. Top 3 peserta dengan skor tertinggi ditampilkan dengan medali. Semua orang bisa melihat ranking terbaru kapan saja.

Auto Leaderboard Live Update
// 03 — Pendaftaran Peserta

Cara Daftar sebagai Peserta

📋

Form Pendaftaran

Tersedia di halaman publik. Isi semua kolom yang wajib diisi: pilih event, nama pengguna aplikasi, link profil, dan jam tampil (WIB).

🔑

Kode Unik Pendaftaran

Setelah mendaftar, sistem memberi kode unik. Gunakan kode ini di fitur Cek Status untuk memantau apakah pendaftaran sudah disetujui admin.

⏳

Status Pendaftaran

Ada tiga kemungkinan status: Menunggu (belum ditinjau admin), Disetujui (bisa ikut event), atau Ditolak (tidak lolos seleksi).

📎

Data yang Dibutuhkan

Pilih event · Username aplikasi · Link profil atau akun · Jam perform (WIB). Tidak perlu buat akun — cukup isi form dan simpan kode unik kamu.

// 04 — Sistem Penilaian

5 Kriteria Penilaian

Setiap peserta dinilai berdasarkan lima aspek roleplay yang terstandarisasi. Nilai dari semua juri digabungkan otomatis.

🤝
Interactivity

Kemampuan berinteraksi dengan peserta lain dan merespons situasi secara aktif selama roleplay berlangsung.

Kriteria 1
🌊
Immersion

Seberapa dalam peserta "masuk" ke dalam karakter dan dunia fiksi — menjaga konsistensi dan suasana cerita.

Kriteria 2
💡
Creativity

Orisinalitas ide, cara bercerita, dan bagaimana peserta menambahkan warna unik pada alur roleplay.

Kriteria 3
🎲
Improvisation

Kemampuan beradaptasi dan berimprovisasi secara natural saat muncul situasi tidak terduga dalam roleplay.

Kriteria 4
👗
Costume

Kesesuaian kostum atau penampilan visual dengan karakter yang dibawakan selama event virtual berlangsung.

Kriteria 5
⚡

Bagaimana Nilai Dihitung?

Setiap juri memberikan nilai untuk kelima kriteria di atas per peserta. Sistem secara otomatis menjumlahkan semua nilai dari semua juri dan menghitung rata-rata atau total keseluruhan untuk menentukan posisi di leaderboard.

// 05 — Leaderboard

Papan Peringkat Otomatis

🥇

Peringkat 1 — Medali Emas

Peserta dengan total skor tertinggi ditampilkan di posisi teratas dengan ikon medali emas. Informasi detail skor per kriteria juga ditampilkan.

🥈

Peringkat 2 & 3 — Perak & Perunggu

Dua peserta berikutnya juga mendapat tampilan khusus dengan medali perak dan perunggu, sesuai total nilai mereka.

🔄

Update Otomatis Tanpa Reload

Saat juri memasukkan nilai baru, posisi leaderboard langsung berubah secara otomatis. Tidak perlu menyegarkan halaman untuk melihat hasil terbaru.

🎭

Filter per Event

Leaderboard bisa difilter berdasarkan event tertentu. Pilih event dari dropdown dan papan peringkat langsung menampilkan data peserta event yang dipilih.

// 07 — Dashboard Admin

Fitur-Fitur di Panel Admin

Panel admin adalah pusat kendali seluruh event. Berikut semua menu yang tersedia.

📊
Dashboard

Ringkasan statistik keseluruhan: total event aktif, total peserta terdaftar, dan jumlah juri. Akses cepat ke semua menu.

🎭
Manajemen Event

Buat, edit, dan hapus event. Atur nama, deskripsi, status aktif/nonaktif, dan semua detail event dari satu halaman.

👥
Manajemen Peserta

Lihat semua peserta yang mendaftar, tinjau data mereka, lalu setujui atau tolak pendaftaran sebelum event dimulai.

⚖️
Manajemen Juri

Tambah juri baru, tetapkan ke event tertentu, dan kelola akun juri. Setiap juri mendapat akses panel terpisah.

🏆
Leaderboard Admin

Tampilan leaderboard khusus admin yang menyertakan rincian skor per juri dan per kriteria untuk semua peserta.

🖼️
CMS Landing Page

Edit konten halaman publik langsung dari dashboard: teks hero, deskripsi platform, informasi kontak, dan elemen visual.

⚙️
Pengaturan

Konfigurasi umum aplikasi, pengaturan akun admin, dan opsi lanjutan untuk menyesuaikan platform sesuai kebutuhan.

🔥
Setup Firebase

Upload file firebase-config.json untuk menghubungkan aplikasi ke database Firebase milikmu sendiri. Cukup drag & drop.

🔐
Manajemen Akun Admin

Tambah admin baru dengan aktivasi kata sandi. Admin dapat memiliki nama, nomor WA, dan email yang berbeda-beda.

// 08 — Teknologi

Dibangun dengan Apa?

Ryusei menggunakan teknologi web modern yang ringan dan mudah di-deploy secara gratis.

HTML / CSS / JS
Firebase RTDB
Firebase Auth
GitHub Pages
Vanilla JS
Responsive CSS
🔥

Firebase Realtime Database

Semua data event, peserta, nilai, dan juri disimpan di Firebase RTDB. Perubahan data langsung tersinkronisasi ke semua pengguna yang terhubung tanpa reload halaman.

🌐

GitHub Pages (Hosting Gratis)

Aplikasi di-host di GitHub Pages secara gratis. Tidak perlu biaya server — cukup punya akun GitHub dan Firebase untuk menjalankan platform ini.

🔐

Firebase Authentication

Login admin dan juri diamankan dengan Firebase Auth menggunakan email dan password. Setiap sesi tervalidasi secara otomatis oleh Firebase.
